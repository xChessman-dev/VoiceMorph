# Установка VoiceMorph

Первая тестовая версия для Windows 11 x64. .NET уже включён. Режим **DSP** готов к запуску без Python и скачивания нейромоделей.

1. Скачайте ZIP из [Releases](https://github.com/xChessman-dev/VoiceMorph/releases).
2. Распакуйте всю папку в каталог с правом записи, например `F:/Apps/VoiceMorph`.
3. Запустите `VoiceMorph.exe`, выберите DSP, микрофон и аудиовыход.
4. Для игры, Discord и OBS виртуальный кабель устанавливается отдельно: **CABLE Input** на выходе приложения, **CABLE Output** в целевом приложении.
5. Сначала проверьте звук на локальной записи. Другие приложения не должны одновременно отправлять обработку в тот же кабель.

## Необязательный нейроголос

RVC-runtime и голоса не входят в ZIP. Чтобы установить движок из распакованной папки, выполните в PowerShell:

```powershell
./tools/setup-rvc-runtime.ps1 -RuntimeRoot 'F:/VoiceMorphRuntime'
$env:VOICEMORPH_RUNTIME_ROOT = 'F:/VoiceMorphRuntime'
./VoiceMorph.exe
```

Для GPU-варианта требуется минимум 9 ГБ свободного места во время установки, совместимая видеокарта и её драйвер. Движок скачивается только при явном запуске скрипта. Затем импортируйте собственную или разрешённую модель. Индекс включайте только для доверенного файла.

RVC экспериментален: возможны задержка и артефакты. DSP не клонирует личность и манеру речи. Сходство «1:1» не обещается.

Приложение без цифровой подписи. Не отключайте защиту Windows; сверяйте SHA-256 с файлом рядом с ZIP. Настройки и записи пользователя не включены.
